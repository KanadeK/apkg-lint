# Changelog

All notable changes are documented here.

## [0.1.0] - 2026-07-30

### Added

- Read-only legacy v1/v2 and current v3 APKG inspection.
- Collection schema 11–18 adapters.
- Twenty deterministic database, note, cloze, template, media, and sharing rules.
- Text, JSON, standalone HTML, and SARIF output.
- Shared-deck and backup profiles, fail thresholds, severity overrides, ignores,
  and resource limits.
- Recursive directory scanning and stable exit codes.
- Composite GitHub Action.
- Clean modern and intentionally broken legacy example packages.
- Cross-platform CI, security audit, deterministic packaging, checksum manifest,
  and release history/contributor gate.
